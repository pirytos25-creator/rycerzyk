# Rycerzyk — Strażnik Torunia

Sterowalna scena 3D z rycerzem, dziedzińcem inspirowanym gotykiem Torunia, treningiem miecza i strzelaniem z łuku.

Otwórz [grę](./index.html), aby uruchomić ją lokalnie lub po publikacji przez GitHub Pages.

Sterowanie: `WASD` — ruch, `Shift` — bieg, `1/2` — broń, `LPM` — atak/strzał, `PPM + mysz` — kamera, `F` — blok, `Esc` — pauza.

Modele GLB i instrukcja znajdują się w tym repozytorium. Twarz wykorzystuje skan Lee Perry-Smith / Infinite-Realities na licencji CC BY 3.0; pełne informacje są w [LICENCJE.txt](./LICENCJE.txt).
